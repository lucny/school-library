# v1.0 Release Checklist (GitHub)

## 1) Pred release
- [ ] Aktualni kod je stabilni (lokalni check a testy prochazi).
- [ ] `README.md`, `RELEASE_NOTES.md` a `docs/` jsou aktualni.
- [ ] `.env` ani jine tajne soubory nejsou ve stagingu.

Doporucene overeni:
- `python manage.py check`
- `python manage.py test`
- `python -m sphinx -b html docs docs/_build/html`

## 2) Git priprava
- [ ] Jsi na vetvi `main`.
- [ ] Mas aktualni zmeny stazene z remote.
- [ ] Working tree je cisty po finalnim commitu.

Priklady prikazu:
- `git checkout main`
- `git pull`
- `git status`

## 3) Finalni commit
- [ ] Finalni commit zprava odpovida konvenci (napr. `docs(release): finalni podklady pro v1.0`).

Priklady prikazu:
- `git add .`
- `git commit -m "docs(release): finalni podklady pro v1.0"`
- `git push`

## 4) Tag v1.0
- [ ] Vytvoren anotovany tag `v1.0`.
- [ ] Tag pushnut na GitHub.

Priklady prikazu:
- `git tag -a v1.0 -m "v1.0 - finalni vyukovy balicek"`
- `git push origin v1.0`

## 5) GitHub Release
- [ ] Vytvorena release z tagu `v1.0`.
- [ ] Pouzity text z `release/github-release-body-v1.0.md`.
- [ ] Odkaz na RTD doplnen do release textu.

Priklad (GitHub CLI):
- `gh release create v1.0 --title "v1.0 - Django Skolni knihovna" --notes-file release/github-release-body-v1.0.md`

## 6) Post-release kontrola
- [ ] Release je viditelna na GitHubu.
- [ ] Tag `v1.0` smeruje na spravny commit.
- [ ] RTD build probehl a docs jsou dostupne.
- [ ] Docker start podle README funguje.
